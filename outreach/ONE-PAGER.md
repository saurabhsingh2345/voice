# A Hindi + English voice agent that runs with the network off

**What it is.** Speech in, reasoning with tool calling, speech out, encrypted
memory — the whole agent, running locally on a consumer Mac. No cloud API, no
per-minute cost, no audio leaving the machine. Every dependency is Apache, MIT
or BSD, enforced by an audit that fails the build.

Every number below is measured on one 18 GiB M3 Pro and regenerated by
`voice-doctor` and `uv run python -m voiceagent.eval.specsheet`. None is copied
from a document.

---

## The gap this sits in

Indian-language **speech quality** is solved and commoditising. Gemini,
ElevenLabs and Cartesia lead it; Sarvam sells Hindi at roughly ₹2.70 a finished
minute; Bhashini gives it away. That is not a market worth entering.

Indian-language **agents that run where the data cannot leave** are not solved by
anyone.

| | Cloud voice agents | Sarvam Edge | This |
| --- | --- | --- | --- |
| Runs on-premise / on-device | ✗ | ✓ | ✓ |
| Indic speech in and out | ✓ | ✓ (10 langs) | ✓ (Hindi) |
| LLM reasoning | ✓ | ✗ | ✓ |
| Tool calling | ✓ | ✗ | ✓ |
| Persistent memory | ✓ | ✗ | ✓ (encrypted) |
| Available today | ✓ | no announced date | ✓ |

Sarvam Edge is genuinely impressive and genuinely narrow: 74M parameters,
~294 MB, speech I/O only. Everything with an agent layer is a cloud API.

**Why now.** The DPDP Rules were notified 13 November 2025. Consent Manager
obligations begin 13 November 2026; full operational compliance is due
**13 May 2027**, with penalties to ₹250 crore. Voice is biometric-adjacent, and
biometric data needs explicit, unbundled, purpose-specific consent. For BFSI,
insurance and healthcare, "we would prefer it stayed inside" is becoming
"procurement requires it stays inside," on a date.

India data residency is still someone else's cloud. This is your hardware.

## The measurements

**Licences — the diligence artifact**

- Permissive-only audit: **clean**. Model violations: 0. Dependency violations: 0.
  Recorded exceptions: **none**.
- Enforced in code: `voice-doctor` exits non-zero on a violation anywhere in the
  installed tree.

Worth knowing what that catches: our previous Hindi model shipped MIT *weights*
on top of a dependency tree carrying CC-BY-NC, GPL and LGPL. A permissive model
card is not a clean tree. The audit is what tells the difference, and it failed
the build until the tree was clean.

**Speech**

| | |
| --- | --- |
| Hindi synthesis | **RTF 0.68 median**, 0.83 worst — synthesis keeps up with playback |
| Hindi recognition | **CER 9.2%** on a deliberately hard held-out set; 4.8% on ordinary Hindi |
| Time to first audio | **1.8 s warm**, 2.4 s cold |
| Resident memory | 1.33 GiB TTS · 2.31 GiB STT · 2.16 GiB LLM; whole pipeline under 12 GiB |
| Host | 18 GiB Apple Silicon. Not a GPU cluster. |

RTF is strongly load-sensitive — 0.63 on an idle host, 1.18 with a VM running
alongside. Quoted here with the host state it was measured on.

The hard set was built from code-switching, digits, retroflex clusters and nuqta
consonants, chosen because they break things. That is why its CER is the number
we lead with.

**Quality, stated as narrowly as the evidence allows**

AI4Bharat's SpeechArenaBench is 120,000 pairwise comparisons by 1,900 native
raters across seven TTS systems, with audio and preferences both released. On 40
held-out code-mixed sentences from it, scored by round trip:

> This engine lands **inside the intelligibility band of the six working cloud
> systems**, and separates decisively from the one that fails — 92% paired wins
> over IndicF5, a system those raters approved 13% of the time. At RTF 0.58.

Cloud-competitive intelligibility, entirely offline. We do not claim to beat any
of those six, and the section below says why we could not support it if we did.

## What we do not claim, and what does not work yet

Published because an offline product is bought on trust, and every item here is
discoverable in week one.

- **Naturalness is unmeasured.** Round-trip scoring is blind to prosody — a
  monotone reading with every phoneme correct scores at ceiling. Measuring it
  needs listeners. We would rather say so than estimate.
- **Our own metric cannot rank the band it places us in.** Calibrated against 654
  human-rated clips it predicts a native speaker's verdict at AUC 0.625 among
  working systems, against 0.500 for a coin flip. It is a reliable alarm for
  broken speech and nothing more. We publish this because it is the reason our
  quality claim is narrow.
- **The intelligibility ceiling is ~90%, not 100%.** A flawless human recording
  scores 90.2% on this scorer. Read every other number against that.
- **Hindi and English only.** Other Indic scripts raise an error rather than
  guessing. More languages need a checkpoint that speaks them.
- **Sub-second turn latency is not met** — 1.8 s warm.
- **Models are not in the app bundle.** 1.3 GB app, ~7.6 GB of weights that
  download once. Offline after provisioning; pre-staged for air-gapped sites.
- **The desktop app is not yet signed or notarised.**
- **No acoustic echo cancellation** — headphones, or a speakerphone hears itself.
- Every figure here is one machine and one speaker's enrolled voice.

## What a deployment looks like

Installed by hand, on a call, by the person who built it. No self-serve, no
platform, no data collection — there is nowhere for the data to go.

A scoped on-prem pilot runs **₹50,000–2,00,000**. Per-device or per-seat
licensing for embedding. Priced against the cost and risk of the compliance path
you would otherwise take, not against ₹2.70 a minute of rendered audio — you are
not buying minutes.

**The ask:** fifteen minutes, and a recording of the whole thing running with
the network physically off.
