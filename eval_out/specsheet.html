Why 9.2 % and not 4.8 %

Ordinary Hindi transcribes at 4.8 % character error. The 9.2 % above is on the held-out set, which was built to be hard on purpose: mid-sentence code-switching, digits, retroflex clusters and nuqta consonants — the things chosen because they break systems. Both numbers are real; only one of them is a fair thing to quote at you.

Licences

Enforced in code

Permissive only — Apache, MIT, BSD. voice-doctor exits non-zero on a violation anywhere in the installed dependency tree, so this is a build gate rather than a policy document. It has blocked real models, and it is why the Hindi engine was replaced.

Recorded exceptions1 — num2words, LGPL
The one exception, stated

num2words is LGPL-2.1 and turns digits into words. The LGPL permits commercial use of an unmodified library, but carries an obligation the permissive set does not: recipients must be able to replace it. Shipping it as an ordinary importable package satisfies that; freezing it into one opaque binary would not — which is a live constraint on the desktop build, not a footnote.

What it does not do

Limits
  • Hindi only, among Indian languages. The previous engine covered eleven; this one covers one. Other Indic scripts raise a named error rather than being spoken badly.
  • Hindi needs an enrolled voice. The engine clones and has no built-in speaker, so Hindi is silent until a voice is enrolled with consent. No default speaker ships — it would be a real person's voice with no consent record attached.
  • Listening is a choice. The loop hears English by default; Hindi input costs about 2.3 GiB against 228 MiB. On an 18 GiB machine that is a flag, not a default.
  • No quality verdict. Intelligibility and latency are measured. Naturalness is not.
  • Sub-second turns are not met. Roughly 1.8 s to first audio, warm.

Reproduce it

One command

The sheet refuses to run on a busy machine. That gate exists because a Hindi real-time factor was once measured at 6–12 and nearly published; a virtual machine had the host at 44× load per core. The same code reads 0.63 idle.

uv run python -m voiceagent.eval.specsheet

Add --check to test only whether the machine is quiet enough; it exits non-zero when it is not.
