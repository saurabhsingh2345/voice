Registers

Longer passages, where drift shows up

A single short line hides accent drift. These run seven to nine seconds across several sentences, which is where Indic synthesis is reported to slip. One voice throughout, cloned from a five-second reference.

Two ways to run it

Hosted, or entirely on your own machine

Cloud

Generate on the web or over the API

  • Studio in the browser, nothing to install
  • An API key and a few lines of code — see the docs
  • Clone a voice with a recorded consent statement
  • Priced in rupees, paid over UPI
Desktop · offline

Runs with the network switched off

  • Every model runs on your hardware
  • No audio leaves the device, because there is nowhere to send it
  • Every dependency permissively licensed, checked by a build gate
  • For teams whose recordings legally cannot go to a cloud
What we do not claim. Naturalness we have not measured — our own scorer is blind to prosody, and we would rather say so than estimate. On intelligibility we land inside the band of the major cloud systems on held-out sentences from a benchmark rated by 1,900 native speakers. We are not claiming to beat them, and the measurements behind that sentence are published.
